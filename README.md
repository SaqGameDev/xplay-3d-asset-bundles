# XPlay 3D Asset Bundles — Download Links

64 original horror 3D asset bundles by **MR SAQLAIN PRODUCTIONS**, listed on the XPlay store.

Each bundle contains 24 unique pieces, built procedurally in Blender only — no AI-generated
models or textures, no downloaded or copied assets, no copyrighted horror characters or
franchises. Atmospheric horror only: no extreme gore, no human remains.

## What's in each bundle

- 24 FBX files + 24 GLB files + a combined scene
- Master.blend
- 5 preview renders (1920×1080)
- Metre scale, origin at base centre, procedural PBR materials, low-to-mid poly
- Works in Blender, Unity, Unreal Engine and Godot via FBX or glTF/GLB import
- Models are static props (no rigs, no animations)
